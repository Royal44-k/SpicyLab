# 食品安全、行业标准与适用边界

核验日期：2026-09-17。本文是产品与内容工作的核查框架，具体经营地、供餐对象和工艺有差异时读取官方现行全文，不把已发布标题当作已完成合规判断。

## 按业务判断

| 业务 | 优先核查 | 不应混淆 |
|---|---|---|
| 纯菜谱内容与家庭教程 | 内容准确、安全提示、素材来源、隐私与广告 | 不因有菜谱就认定经营实体餐馆 |
| 食品销售/餐饮配送 | 经营许可或备案、网络交易与履约、冷链和售后 | 不能把纯内容原型直接当食品经营资质 |
| 实体厨房/餐饮培训供餐 | GB 31654、食品安全操作规范及当地要求 | 家庭示例工序不替代企业HACCP/管理记录 |
| 医疗/特殊人群膳食 | 专业资质、医学适用性、健康数据 | 口味偏好不是医疗处方 |

## 熟度与保存内容的使用方式

家庭教程可引用 FoodSafety.gov 的简明参考：禽肉约74℃、绞肉约71℃、整切牛猪羊肉约63℃并静置3分钟、鱼约63℃、剩菜复热约74℃。这些是食物内部测量值而非锅温，具体种类与适用范围看原表。不要把不同指南的最低值拼成更低门槛，也不要将“余温可能升高”写成保证。[参考表](https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperatures)

WHO家庭教育材料提示熟食室温不超过2小时、易腐食品及时冷藏（宜低于5℃）、热食保持高于60℃，并避免室温解冻。具体食品、环境温度和当地指引可能更严格；不要用这一通用规则推定任何自制菜的保质期。[WHO海报](https://www.who.int/docs/librariesprovider2/default-document-library/5keys_en.pdf)

保存时间需要食材类型、熟制方式、冷却过程、包装与温控证据。库存中的“临期”是提醒，不是可食用证明；过期或来源/储存条件可疑时不推荐通过加热挽救。

## 审校风险表

| 风险 | 菜谱必须明确 | 不接受的说法 |
|---|---|---|
| 鸡鸭与绞肉熟度 | 适用测温位置、终点和不足时继续加热 | 只凭汁水清澈/粉红色判断安全 |
| 血制品/内脏 | 合规来源、冷链、彻底熟制 | “新鲜现杀所以能半熟” |
| 鱼/水产 | 淡海水差异、寄生虫与熟制 | 白酒腌制等同消毒 |
| 发酵/腌制 | 经验证配方、盐酸度温度与保存条件 | 任意盐水比长期常温存放 |
| 过敏 | 原料与复合调料配方、交叉接触 | 把花生挑掉就适合花生过敏者 |
| 冷却/再加热 | 时间温度管理、分装与充分复热 | 闻起来正常就安全 |
| 油炸与火焰 | 控制水分、锅负载、设备适用 | 为画面效果让新手往油锅泼水 |

## 内容治理

食品安全问题按严重度处理，保存问题版本和来源；必要时下线菜谱、停止推荐，给出可识别的修订说明。用户上传内容有审核、举报和申诉入口。来源注明不等于获得照片或整篇配方表达的复制授权；传统菜名也不能证明某张图片可自由使用。

对健康功能，只提供有依据的一般饮食信息。精确营养需原料成分、净可食重量、烹饪损耗与分量来源；没有数据不写“零糖、低钠、适合糖尿病”等可误导结论。
