# UI风格、地域美学与可维护设计规范

## 视觉概念必须解释服务

SpicyLab用铁锅与真实成菜质感表达开火行动；首页聚焦“家里有什么”，其他任务使用米纸浅底方便读配方和采购。黑、红、黄铜不是所有餐饮产品的默认模板。婴幼儿辅食、清淡粤菜、专业厨房SaaS有不同的信息密度与语气。

|---|---|---|
| 主文字 ink | `#171412` | 浅色页正文 |
| 深底 charcoal | `#141310` | 首页及品牌氛围 |
| 深卡 iron | `#22201C` | 深色结果层级 |
| 米色 rice | `#F6F1E6` | 中性背景 |
| 纸色 paper | `#FBF8F0` | 详情、采购、偏好阅读 |
| 辅助文字 muted | `#756E63` | 每个背景单独测对比 |

| 草木绿 sage | `#58704D` | 已选/已购，配合图标文字 |

素材中的颜色不是自动合格的色对。正文AA目标4.5:1、大字3:1；交互控件和焦点可识别性另查相关要求。[WCAG 2.2](https://www.w3.org/TR/wcag/)

推荐令牌在`assets/templates/design-tokens.json`。可点击区域建议至少44–48 CSS px，作为厨房使用设计目标；WCAG 2.2 AA的2.5.8为24×24及例外条件，不能错误声称44px是其最低门槛。手湿、视距较远时可再放大。

## 排版、空间与密度

系统中文无衬线用于长文本与操作，楷/宋可用于短品牌或章节标题，不用装饰字承载详细步骤。正文建议16–18px、行高1.5–1.7；大字烹饪模式20–24px；辅助说明通常不低于12–14px，实际需放大测试。首页大标题允许小屏换行，不把`nowrap`作为通用要求。

间距采用4/8px基础节奏，页面边距16–24px，卡片圆角12–18px。一个屏幕一个明确主行动，多个同权按钮减少选择确定性。配方量采用右对齐数值、明确单位；“已拥有/相关/缺少”用文字与图标并存，不仅用红绿。

## 组件规范

- **食材输入**：外部可见label、可理解示例、添加按钮、Enter语义、错误/空白输入反馈；中文组合输入不误提交。
- **食材chip**：选中与可删除区别；长名不挤掉删除按钮，触控区域不只等于小×的图形。
- **菜卡**：真实对应图、菜名、时间口径、关键缺料、相关原因；未知份量不显示100%可做。结果改变时图与文一起变。
- **详情头图**：16:9是当前例子，适配具体裁切；文字放独立可读区域或经对比验证的遮罩，鱼头等关键部位不裁没。
- **采购行**：材料、数量单位、来源计划和已购状态；超过一行时不挤压复选框；撤销方便。
- **分段选择**：控件label和选中状态可读，辣、麻、咸、油不混合一个“口味”值。
- **导航与安全区**：视觉延伸到底端，内容和触控避开系统手势区；固定导航不会遮最后一行。
- **反馈态**：加载骨架不伪造结果、无结果解释可改条件、图片失败明确占位且可重试。

## 地域审美方案库（设计提案，不是文化定论）

| 方向 | 材质/色彩 | 摄影与文字 | 应避免 |
|---|---|---|---|
| 川味家常 | 陶碗、木案、米白与椒红 | 调料层次、近景刀工，清晰技术说明 | 所有菜都铺满红油、统一辣度 |
| 重庆江湖 | 深铁锅、搪瓷、小面积热红 | 有锅气的动态近景、短促行动语言 | 火焰遮菜、只剩霓虹夜店感 |
| 湖湘鲜辣 | 蒸汽、白瓷、鲜椒色与竹绿 | 鲜料质地、蒸盘完整结构 | 把麻椒当所有湘菜主角 |
| 赣味烟火 | 米色、深木、瓦罐、克制墨色 | 地方食材特写、粉条与蒸粉区分 | 用青花瓷符号代替真实地方内容 |

在跨菜系产品中保持同一组件和阅读逻辑，地域差异主要进入摄影、编辑文案和少量色彩；不要每切一次菜系就重学导航。

## 图片生产到接入

先生成每菜拍摄简报：名称、部位、材料、烹饪法、汤汁量、餐具、视角、光源、裁切安全范围与禁用元素。写实生成图须检查事实一致性，不能把“逼真”称为“实拍”。

保留母版、生成来源/授权、优化版本、recipeId映射、尺寸、字节数和替代文字。移动运行图按实际显示尺寸及像素密度导出；SpicyLab采用约1200×675 JPG供详情等位置使用，但不把这一个尺寸强制给所有产品。

接入验收：文件存在 → 解码成功 → 映射正确 → 浏览器naturalWidth大于0 → 实际可见 → 打包包含 → 目标部署可访问。只检查HTTP 200可能拿到SPA的HTML回退，需检查Content-Type及解码。所有菜都检查映射，四菜系抽样视觉检查不足以证明全部图文一致。
